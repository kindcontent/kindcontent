# Quy trình Agentic Content

## Giai đoạn 1 — Chiến lược
### 1. Agent Nghiên cứu
- Phân tích thị trường, đối thủ, insight khách hàng
### 2. Agent SEO & Từ khóa
- Từ khóa, search intent, khoảng trống nội dung
### 3. Agent Kế hoạch
- Persona, content pillar, lịch nội dung
### 4. 👤 Người duyệt chiến lược
- Human-in-the-loop

## Giai đoạn 2 — Thực thi
### 5. Agent Brief
- Dàn ý, outline, thông điệp chính
### 6. Agent Viết
- Bản nháp bài blog, fanpage, PR
### 7. Agent Hình ảnh & Video
- Visual, thumbnail, kịch bản video ngắn
### 8. Agent Biên tập
- SEO on-page, kiểm chứng thông tin, giọng thương hiệu
### 9. 👤 Người duyệt nội dung
- Human-in-the-loop
- Chưa đạt → quay lại Agent Viết

## Giai đoạn 3 — Phân phối
### 10. Agent Chuyển thể
- 1 bài gốc → nhiều định dạng (post, reel, email)
### 11. Agent Đăng bài
- Website, Fanpage, TikTok, YouTube, Email
### 12. Agent Đo lường
- Traffic, tương tác, chuyển đổi

## Vòng lặp
- Kết quả đo lường → quay lại Giai đoạn 1 – Chiến lược
- Tối ưu chu kỳ sau
