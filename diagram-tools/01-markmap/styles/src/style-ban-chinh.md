# Quy trình Agentic Content

## 1. Chiến lược (Strategy)
### Agent Nghiên cứu
- Phân tích thị trường, đối thủ
- Insight khách hàng
### Agent SEO & Từ khóa
- Nghiên cứu từ khóa, search intent
- Khoảng trống nội dung
### Agent Kế hoạch
- Persona, content pillar
- Lịch nội dung
### 👤 Người duyệt chiến lược
- Human-in-the-loop

## 2. Thực thi (Execution)
### Agent Brief
- Dàn ý, outline, thông điệp chính
### Agent Viết
- Bản nháp: blog, fanpage, PR
### Agent Hình ảnh & Video
- Visual, thumbnail
- Kịch bản video ngắn
### Agent Biên tập
- SEO on-page, kiểm chứng thông tin
- Giọng thương hiệu
### 👤 Người duyệt nội dung
- Human-in-the-loop
- ↩ Chưa đạt → quay lại **Agent Viết**

## 3. Phân phối (Distribution)
### Agent Chuyển thể
- 1 bài gốc → nhiều định dạng (post, reel, email)
### Agent Đăng bài
- Lên lịch & đăng
- Website · Fanpage · TikTok · YouTube · Email
### Agent Đo lường
- Traffic, tương tác, chuyển đổi

## 🔁 Vòng lặp phản hồi
- Kết quả đo lường → quay lại **Giai đoạn 1 – Chiến lược**
- Tối ưu chu kỳ sau
